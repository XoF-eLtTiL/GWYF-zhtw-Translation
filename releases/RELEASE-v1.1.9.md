# GWYF zh-TW Translation Pack v1.1.9

## 更新內容

- 補充目前遊戲版本新增的設定、語言、遊戲模式與製作人員文字
- 修正本機新增翻譯中黏連在同一行的項目與 TMP 標籤格式
- 手動整合包關閉 BepInEx Console
- 手動整合包不再安裝 GWYF Translation Updater
- Thunderstore 版不包含 BepInEx framework，改由 Thunderstore 依賴安裝
- Thunderstore 版仍將翻譯放在 `BepInEx/config/Translation`

## 安裝

- 手動整合包：解壓縮到遊戲根目錄。
- Thunderstore 版：使用 Thunderstore Mod Manager、r2modman 或 Gale 安裝。

## 注意

- 手動整合包不會自動從 GitHub 更新翻譯。
- Thunderstore 依賴：BepInExPack、XUnity AutoTranslator。
